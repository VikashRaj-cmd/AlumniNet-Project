📋 QUICK SETUP IN POSTMAN
================================================================

1. Create a new Collection → name it "AlumniNet API"

2. Create a Collection Variable:
   - Variable : baseUrl
   - Value    : http://localhost:5000/api

3. Create folders inside the collection:
   - Auth
   - Users
   - Events
   - Jobs / Internships
   - Mentors

4. For protected routes, go to:
   Authorization tab → Type: Bearer Token
   → Paste the token received from Login or Register response

5. Make sure backend is running:
   cd Backend
   npm run dev

6. Make sure MongoDB is running (MongoDB Compass connected)
